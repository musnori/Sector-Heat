# 資金の温度計

時価総額上位20銘柄の動きと、今どこにお金が流れているかを1時間ごとに集計して、Webのダッシュボードで表示するツールです。GitHub Actions（データ集め）と GitHub Pages（表示）だけで動くので、サーバー代はかかりません。

## 見ているもの

| 指標 | 取得元 | 意味 |
|---|---|---|
| ステーブルコイン残高の7日変化 | DefiLlama | 実需のお金がそのチェーンに入ってきているか |
| DEX出来高の7日変化 | DefiLlama | 実際に取引が活発になっているか |
| TVLの7日変化 | DefiLlama | DeFiに預けられているお金の増減 |
| 建玉(OI)の24時間変化 | Hyperliquid（無い銘柄はBinance→OKX） | レバレッジのお金がどれだけ入ったか |
| 資金調達率(FR) | Hyperliquid（無い銘柄はBinance→OKX） | ロングが混みすぎていないか |
| セクターの24時間の値動き | CoinGecko | 上位銘柄が属するセクター（ソラナ系・AI系・ミーム系など）の勢い（詳細に出します） |
| 価格トレンド（7日線・30日線） | Hyperliquid の4時間足（無い銘柄は Binance → OKX） | 上昇の流れに乗っているか、落ちている最中か |
| RSI（1時間足・4時間足） | Hyperliquid の足（無い銘柄は Binance → OKX） | 14本のRSI。70以上は買われすぎ、30以下は売られすぎ |
| OIと価格のズレ | 上の2つから計算 | 新しい買いで上がっているのか、OIだけ膨らんで危ないのか |
| 今の資金の流れ | 上の指標から計算 | 上位銘柄の値動きと建玉から、資金が入っている銘柄・抜けている銘柄をひとことで |
| 取引できるトークン | DefiLlama + CoinGecko + Hyperliquid + Ostium | チェーンの通貨の詳細に出す、各チェーンのDeFiトークン・エコシステム銘柄のうち、Hyperliquid か Ostium で取引できるもの（出来高順） |
| 上位20銘柄の表 | CoinGecko + Hyperliquid + Binance/OKX + DefiLlama | 価格、24時間・7日の値動き、7日線との差、FR、OI、状態（強い・初動・押し目・過熱・様子見・弱い）と理由。詳細にトレンド、OIと価格のズレ、出来高、セクター、チェーンの温度 |

状態が「強い・初動・押し目」で、「OIに危ないズレなし」＋「FRが0.05%未満」がそろった銘柄のうち、上から最大3つに **◎ 条件そろい** が付きます。エントリーを検討する候補の目安です。

## 今の資金の流れ

ページの一番上に、ひとことのまとめ（「20銘柄中 15銘柄が24時間で上昇。資金が入っているのは SOL・SUI。抜けているのは TON」など）と「条件そろい」の銘柄を出します。
24時間で+2%以上の銘柄に「資金が入っている」、−2%以下の銘柄から「抜けている」とします（`FLOW_MOVE`）。建玉が価格の影響を除いて+5%以上増えながら上がっている銘柄は「新しい買いを伴っている」と書きます。

## 上位20銘柄の読み方

監視するのは、**Hyperliquid か Ostium で取引できる銘柄を時価総額の大きい順に20個**です（BTCも含みます。ステーブル・ラップ系は除外。`TOP_RANK`で変更可）。取引所の自社トークンやトークン化された資産のように、どちらでも取引できない銘柄は飛ばして、次の順位から詰めます。
状態は、**その銘柄自身の指標だけ**で決めます（BTCなど他の銘柄とは比べません）。上から順に当てはめます。

- **過熱**（赤）: 24時間で+10%以上（`HOT_MOVE`）、またはFRが0.05%以上
- **強い**（緑）: 4時間足が上昇トレンド（価格 ＞ 7日線 ＞ 30日線）で、価格がまだ7日線より上
- **押し目**（紫）: 上昇トレンドの中で、24時間で−2%以下（`DIP_MOVE`）、または価格が7日線を割った
- **初動**（青緑）: 上昇トレンドではないが、価格が7日線を上抜けて24時間で+2%以上（`EARLY_MOVE`）
- **弱い**（青）: 4時間足が下落トレンド
- **様子見**（灰）: どれにも当てはまらない

一覧は表になっていて、状態順・24h順・時価総額順に並べ替えられます。各行には価格、24時間の値動き、7日の値動き、48時間の価格の線、7日線との差、RSI（1時間足・4時間足）、FR、OIの24時間変化、状態が出ます。行をタップすると、状態の理由、30日線との差、OIと価格のズレ、出来高、時価総額、属しているセクターの24時間の値動きが開きます。
ETH・SOL・BNBのようにチェーンの通貨であれば、そのチェーンの温度（ステーブルコイン・DEX出来高・TVLの7日変化）と、そのチェーンで取引できるトークンも詳細に出します。
「Layer 1」「Ethereum Ecosystem」のような広すぎるカテゴリはセクターとして出しません（`EXCLUDE_CAT`）。Hyperliquidにある銘柄は、詳細のリンクから取引画面が開きます。

## セットアップ（15分くらい）

1. **CoinGeckoのDemo APIキーを取る**
   coingecko.com でアカウントを作り、Developer Dashboard から Demo キーを発行します（無料）。

2. **GitHubにリポジトリを作ってファイルを置く**
   このフォルダの中身をそのまま push します。

3. **キーをSecretsに登録する**
   リポジトリの Settings → Secrets and variables → Actions → New repository secret
   名前: `COINGECKO_API_KEY` / 値: 手順1のキー
   ※キーはコードやチャットに直接貼らないでください。

4. **GitHub Pagesを有効にする**
   Settings → Pages → Source を「Deploy from a branch」、Branch を `main` と `/docs` にして保存します。

5. **初回のデータ取得を手動で動かす**
   Actions タブ → `update-data` → Run workflow。
   成功すると `docs/data.json` がコミットされ、Pagesの URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）で表示されます。以降は毎時自動で更新されます。

## 手元で見た目を確認する

```bash
pip install -r requirements.txt
python scripts/fetch_data.py --mock      # サンプルデータを作る（手元で見た目を確認する用。サイトには載せません）
python -m http.server -d docs 8000
# ブラウザで http://localhost:8000/?mock を開く
```

本番データで試す場合は `COINGECKO_API_KEY=xxxx python scripts/fetch_data.py` を実行します。

## 知っておいてほしいこと

- **先物データ**: まず Hyperliquid の公開APIから取ります。Hyperliquid に無い銘柄だけ Binance → OKX を試します（GitHub Actions はアメリカのサーバーなので Binance はブロックされがちです）。どれもダメなときは FR と OI なしで計算し、画面に警告を出します。価格トレンドは4時間足から取ります（Hyperliquid にある銘柄はそこから、無ければ Binance → OKX）。
- **建玉の24時間変化**: Hyperliquid は現在の建玉しか返さないので、このツールが毎時保存した値と比べます。この版に更新してから24時間後に表示されます。
- **銘柄のセクター情報**: CoinGecko から少しずつ（1回の更新で最大10銘柄、週1で取り直し）取るので、全銘柄が埋まるまで3〜4時間かかります。その間は画面に警告が出ます。取った情報は `cache/coin_meta.json` に保存されます。
- **履歴は溜まるほど賢くなる**: セクターの7日変化と48時間の価格の線は、このツール自身が貯めた履歴から計算します。セクターの7日変化は、動かし始めて7日後から使われます。
- **Actionsの遅延と停止**: スケジュール実行は混雑時に数分〜十数分遅れることがあります。また、リポジトリに60日間動きがないと GitHub がスケジュールを止めることがあるので、止まっていたら Actions タブから再開してください。
- **状態とスコアは目安**: どれもBTCとの比較やチェーン同士の順位なので、全体が下げ相場でも「相対的にマシな所」が上に来ます。

## カスタマイズ

`scripts/fetch_data.py` の上の方で変えられます。

- `CHAINS`: 監視するチェーンと先物銘柄の組み合わせ
- `WEIGHTS`: 各指標の重み
- `FR_HOT` / `FR_CALM` / `OI_HOT`: 「過熱気味」「静かに流入中」の判定ライン
- `MIN_CAT_MCAP` / `MAX_CATS`: 見るセクターの最低時価総額と件数
- `PX_MOVE` / `OI_MOVE` / `OI_SURGE`: OIと価格のズレを判定するライン
- `TOKENS_PER_CHAIN` / `TOKEN_MIN_TVL` / `TOKEN_SHARE`: 取引できるトークンの件数と拾う条件
- `OSTIUM_FALLBACK`: Ostium の銘柄一覧が取れなかったときに使うリスト
- `TOP_RANK`: 監視する銘柄数（初期値20）
- `COIN_ENTRY_MAX`: 「条件そろい」を付ける銘柄の最大数
- `FLOW_MOVE`: 「今の資金の流れ」で入っている／抜けているとする24時間の値動き（初期値2%）
- `RSI_LEN`: RSIの期間（初期値14）
- `HOT_MOVE` / `DIP_MOVE` / `EARLY_MOVE`: 状態の「過熱」「押し目」「初動」の判定ライン
- `EXCLUDE_CAT`: セクターとして出さないカテゴリ名のキーワード

チェーン名は DefiLlama の表記に合わせる必要があります（見つからないものはログに `skip` と出ます）。
