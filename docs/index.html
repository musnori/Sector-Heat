資金の温度計

読み込み中…
見方
温度（0〜100）
ステーブルコイン流入、DEX出来高、TVL、建玉(OI)の伸びを、チェーン同士で順位づけして合成した値です。資金調達率(FR)が0.05%以上だと15点減点します。
静かに流入中
資金の指標のうち2つ以上がプラスで、FRがまだ0.02%未満。レバレッジが軽いまま実需のお金が入っている状態です。
過熱気味
FRが0.05%以上、またはOIが24時間で+25%以上。ロングが混んでいて、清算で急落しやすい状態です。
恐怖・強欲指数
相場全体の雰囲気を0〜100で表した値です（alternative.me）。25以下は恐怖が強く、75以上は強欲が強い状態です。75以上のときは「条件そろい」を出しません。
トレンド
4時間足の終値で、今の価格が7日平均・30日平均より上にあるかを見ています。価格 ＞ 7日平均 ＞ 30日平均なら上昇トレンド、逆なら下落トレンドです。
OIと価格のズレ
OIはドル建てなので、価格の上げ下げの影響を除いてから比べています。価格が上がってOIも増えていれば新しい買いが入っている、価格が動かないのにOIだけ急増していれば清算で急に動きやすい、という見方です。
条件そろい
「静かに流入中」＋「上昇トレンド」＋「OIに危ないズレがない」＋「恐怖・強欲指数が75未満」を満たしたチェーンです。エントリーを検討する候補の目安で、売買の合図ではありません。
注目トークン
そのチェーンに預け入れ（TVL）の半分以上があるDeFiトークンを、「TVLの7日変化」「価格の7日変化−BTCの7日変化」「回転率（24h出来高÷時価総額）」で順位づけした上位5つです。「資金流入・価格は出遅れ」は、お金は入っているのに価格がまだBTC以下の、先回りの候補です。「急騰後」は対BTCで7日+40%以上で、飛び乗りは危険です。
セクターの対BTC
CoinGeckoのカテゴリ時価総額の変化から、BTCの変化を引いた値です。連続時間は、BTCを上回り続けている時間です。
データ: CoinGecko, DefiLlama, alternative.me, 取引所の公開API。投資判断はご自身で。
